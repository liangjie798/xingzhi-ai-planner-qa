新匿名 Microsoft Edge 会话测试10个候选适配器，只有5个取得可核实结构化报价并默认启用：MF厦航7条、MU东航20条、SC山航6条、KN中联航3条、RY江西航1条。日期、航线及实际采集时间见 [原始结构化结果](live-adapter-results.json)。结果为一次样例，非长期稳定性或最终支付价保证。

CZ、OQ、9H、GS、9C候选尚未完成独立会话或解析验收，默认停用。先前人工样例16家成功，与生产适配器5家通过严格区分；[首轮65项清单](../airlines-20261030/README.md)保留原测试时快照。

- standalone生产构建的对话链路实际返回14条报价，见 [对话元数据](conversation-http.json)。本地未配置模型，明确标记未调用模型，由规则执行工具；未验证用户账户DeepSeek线上调用。

- 全套前端单测116项通过；TypeScript检查、ESLint和Next生产构建通过。
- 新回归覆盖日期、机场、来源、舱位校验，Infinity/售罄拒收，登录/验证停止，模型不得改变已确认查询条件，模型失败后如实回退。

## 行为与边界

只读、单程1成人，每次最多3家；失败不补造报价。官网展示价未保证含税，不能断言全网最低价，也不能与缺失的火车票价比较。火车票仅提供12306入口。

服务器需安装可运行的 Chromium/Edge，并设置 `AIRLINE_BROWSER_ENABLED=1`；默认关闭，不能把本机成功冒充云服务器已验收。部署和配置见应用仓库 `docs/TICKET-SEARCH.md`。
