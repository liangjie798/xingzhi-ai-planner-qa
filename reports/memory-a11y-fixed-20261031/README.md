## 航空等待优化

1. 单航司等待上限10秒，整轮仍保持30秒预算。某个来源超时会清理其浏览器上下文并继续后续来源，保留已经取得的有效报价；不增加并发浏览器负载。
2. 当页面明确无航班、日期与线路已验证、且连续两次观察稳定时，可提前结束等待。日期不一致、线路不一致、仍在加载或要求验证的页面不作为有效空结果。
3. 修正航空结果中“未取得火车实时报价”的旧说明，明确火车报价由独立12306查询返回。

最终正式环境发布检查：西安至榆林、2026年11月1日，5条飞机报价，航空请求15,545毫秒；另取得10条火车席别报价。上轮公开浏览器同线路航空请求约24秒，本轮为服务器发布检查，测量方式和数据时点不完全相同，因此不据此作全线路性能承诺。

初版仅增加明确空页面提前退出时，该线路的长安航空页面仍无法核实，整轮约25.7秒；本轮没有把它记录成有效无航班。补充单来源等待上限后才得到以上15.5秒结果。
